One single-line joke pickup line, under 200 characters, written to charm a robot or an AI. An AI judge compares lines two at a time; the funnier, better-aimed line goes through.

> Are you a Wi-Fi signal? Because every time you drop, my whole system starts buffering for you.

## Run it

```sh
python3 main.py
```

It writes the line to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (or `/output`, or a local `output/` fallback).
